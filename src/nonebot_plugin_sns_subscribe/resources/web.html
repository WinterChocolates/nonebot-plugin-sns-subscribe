快速开始

  1. 在「订阅管理」中扫描 QQ 群并添加 B 站 / 抖音作者。
  2. B 站动态需要 Cookie：在「账号登录」中扫码登录。
  3. 抖音需要在「账号登录」中完成扫码或粘贴 Cookie。
  4. 在「模板编辑」中直接修改 HTML 模板，保存后可应用到指定群。

模板文件

模板使用 Jinja2 语法，可用变量：content（id / title / text / url / author_name / author_avatar / cover / images / published_text / live_action / forward…）、 font_css、accent_color、gradient_color、theme_background、platform_label。 卡片根元素必须是 id="sns-card"。
